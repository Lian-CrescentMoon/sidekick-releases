# 휴대폰에서 Sidekick 사용하기

Android 앱은 PC에서 돌아가는 Sidekick에 연결합니다. 휴대폰에 Claude·Codex·Google AI 로그인이나 API 키를 넣지 않습니다. AI 실행과 작업 파일은 PC에 남습니다.

## 처음 연결

1. PC에서 Sidekick 1.0.0 이상(이 문서와 같은 날 이후 빌드)을 켭니다. Android 8 이상 휴대폰에 Sidekick Remote 1.12.0 APK(`SidekickRemote-1.12.0.apk`)를 설치합니다. 설치 방법은 아래 ‘휴대폰에 앱 설치하기’를 보세요.
2. 같은 Wi-Fi를 사용합니다. 집 밖에서도 쓰려면 PC와 휴대폰을 같은 Tailscale 네트워크에 연결합니다.
3. **PC Sidekick › 설정 › 휴대폰 원격 연결**에서 Wi-Fi 또는 Tailscale 주소를 고르고 **원격 연결 켜기**를 누릅니다.
4. **연결 QR 만들기**를 눌러 연결 QR을 표시합니다. 휴대폰의 Sidekick Remote 앱에서 QR을 스캔하거나, **연결 코드 복사**로 복사한 코드를 붙여 넣습니다. 연결 QR은 2분 동안 한 번만 쓸 수 있습니다.
5. 휴대폰이 연결 요청을 보내면 PC 설정의 **연결 요청 승인 대기**에 표시됩니다. 설정을 열어 두지 않았다면 Sidekick 창에 알림이 뜨고, 누르면 이곳으로 이동합니다.
6. PC에 보이는 **확인 숫자**(예: 123 456)가 휴대폰에 보이는 숫자와 같은지 확인하고 **휴대폰에 보이는 숫자와 같아요**를 선택한 뒤 **승인**을 누릅니다. 숫자가 다르거나 모르는 휴대폰이면 **거부**합니다. 요청을 보낸 주소도 함께 표시되며, 전체 휴대폰 지문은 **자세히**에서 볼 수 있습니다.
7. **대화 보내기·멈추기·설정**, **도구·질문 승인** 권한은 처음부터 켜져 있습니다. 필요 없으면 승인 전에 끕니다. 둘 다 끄면 읽기 전용입니다. 휴대폰에서 보낸 대화는 PC의 지금 권한 모드로 실행되므로, 권한 무시·Autopilot이면 도구가 승인 없이 실행됩니다.

연결된 휴대폰은 PC 설정의 **연결된 휴대폰**에 표시됩니다. 이름을 바꾸거나, 두 권한을 고친 뒤 **권한 저장**을 누르거나, **연결 해제**로 접속 권한을 없앨 수 있습니다. 권한은 이 PC에서만 바꿀 수 있고 다음 요청부터 바로 적용됩니다. 권한을 없애도 PC가 이미 접수해 실행 중인 AI 작업이 취소되지는 않습니다. 필요한 경우 해당 대화에서 중지하세요.

## 휴대폰에 앱 설치하기

1. `scripts/build-android.ps1`를 실행하면 `D:\android-build\sidekick-remote\SidekickRemote-<버전>.apk`(배포용 서명)와 `SidekickRemote-<버전>-debug.apk`(에뮬레이터 시험용)가 만들어집니다. 배포용 서명 키(`~/.sidekick-release/android-release.properties`)가 없으면 배포용 APK는 만들어지지 않으니, 이 경우 휴대폰에 설치하지 마세요.
2. 휴대폰에 `SidekickRemote-<버전>.apk`를 옮기고(USB·클라우드 등) 파일을 열어 설치합니다. Android가 ‘출처를 알 수 없는 앱’ 설치 허용이나 Play Protect 경고를 보일 수 있습니다.
3. **디버그 서명 APK(`-debug.apk`)로 설치한 앱이 있으면 먼저 삭제해야 합니다.** 서명이 달라 배포용 APK를 덮어 설치할 수 없습니다. 삭제하면 이 휴대폰의 서명 키와 연결 정보·초안이 지워지므로 PC에서 ‘연결 해제’ 후 새 연결 QR로 다시 연결합니다. 이후 같은 서명의 새 버전은 삭제 없이 덮어 설치됩니다.
4. 권한: 카메라(QR 스캔 때만), 알림(백그라운드 알림), 인터넷. 앱 첫 사용 때 알림 허용과 배터리 사용 제한 해제 안내가 나옵니다.

### 새 판 받기(업데이트)

PC의 Sidekick 설치본에는 같은 때 만든 휴대폰 앱(배포용 서명 APK)이 들어 있습니다. 휴대폰 앱(1.14.0부터)은 PC에 연결돼 있을 때 6시간에 한 번 PC에 새 판이 있는지 묻고, 있으면 PC에서 직접 받아 크기와 SHA-256을 확인한 뒤 **다운로드 폴더**에 `SidekickRemote-<버전>.apk`로 저장합니다. 받으면 알림과 앱 위쪽 안내로 알려 줍니다. **설치는 직접 합니다** — 다운로드 폴더(안내의 ‘다운로드 열기’)에서 파일을 눌러 설치하세요. 앱은 설치 권한을 요청하거나 설치 화면을 열지 않습니다.

- 받는 것은 앱이 화면에 있거나 백그라운드 알림이 켜져 있을 때만입니다. 끊기면 다음에 이어 받고, 이미 받은 판은 다시 받지 않습니다.
- 바로 확인하려면 휴대폰 위쪽 PC 이름 › **업데이트 확인**.
- Android 8~9에서는 다운로드 폴더 대신 앱 전용 폴더(`내장 저장공간/Android/data/kr.sidekick.remote/files/Download`)에 저장하고, 안내에 그 위치를 보입니다.
- PC 설치본에 휴대폰 앱이 없으면(배포용 APK 없이 묶은 판, 개발 실행) 아무것도 받지 않습니다.

## 휴대폰에서 할 수 있는 일

- 대화 목록과 최근 메시지 보기, Claude·Codex·Google AI 선택, 남은 한도 확인, PC 입력줄과 같은 모델·생각 수준·권한 모드 바꾸기(PC 설정도 함께 바뀌며, ‘대화 보내기·멈추기·설정’ 권한이 필요하고 권한 모드는 ‘도구·질문 승인’ 권한도 필요).
- 기본 작업 폴더나 PC 대화 목록에 있는 폴더에서 새 대화 시작, 텍스트 전송, 실행 중지. 아직 보내지 않은 대기열 글 빼기.
- 현재 대화의 질문에 선택지 또는 직접 입력으로 답하기. 지원하는 도구 요청을 한 번 허용하거나 거부하기.
- 연결이 끊겨도 초안 보관. 전송 결과를 확인하지 못하면 자동으로 재전송하지 않고 안내하기. 새 대화 만들기만은 결과가 불확실하면 같은 요청으로 다시 확인해 PC에 만들어진 그 대화를 열고, 초안은 직접 보내도록 남겨 둡니다.
- PC를 정상 재시작한 뒤 같은 대화를 다시 열기. 저장된 기록을 찾을 수 없거나 여러 후보가 있으면 새 대화를 임의로 만들지 않고 목록에서 고르도록 안내하기.
- **앱 잠금**(기본 꺼짐): 휴대폰 위쪽 PC 이름 › ‘앱 잠금 켜기’. 앱을 5분 넘게 떠났다가 열 때와 보내기·승인 전에 휴대폰 잠금(지문·PIN)으로 확인합니다. 백그라운드 알림은 그대로 오며 알림 내용만 숨겨집니다.

휴대폰 앱이 화면에 있는 동안 열린 대화는 약 1초(한가할 때 3초), 목록은 약 10초 간격으로 갱신합니다. 최근 300개 메시지까지 가져옵니다. 더 오래된 기록은 PC에서 확인합니다.

## 화면을 닫아도 알림 받기

휴대폰 위쪽의 PC 이름을 누르고 **백그라운드 알림 켜기**를 선택합니다. 알림 권한을 허용하면 ‘Sidekick 백그라운드 알림’ 상시 알림이 표시됩니다. 새 PC에서는 PC가 새 소식이 생길 때까지 연결을 붙잡고 있다가 바로 알려 주고, 옛 PC에서는 5~15초 간격으로 확인합니다. 알림에는 대화 제목과, 응답 요청이면 요청 제목·첫 질문(한 줄, 80자)만 표시하고 대화 본문과 도구 인자(명령·주소)는 싣지 않습니다. ‘앱 잠금’을 켜면 알림 내용은 모두 숨겨집니다. 알림을 누르면 해당 대화를 엽니다. 도구를 허용하거나 답변을 전송하려면 앱 안에서 직접 선택해야 합니다.

알림의 **백그라운드 알림 끄기**, 휴대폰 위쪽 PC 이름을 눌러 나오는 ‘연결된 PC’ 창의 **백그라운드 알림 끄기**, 또는 연결 해제로 중단할 수 있습니다. 휴대폰을 다시 켜거나 Android가 앱을 종료한 뒤에는 자동으로 켜지지 않으며, 재시작 직후 ‘눌러서 다시 켜기’ 알림이 한 번 표시됩니다. 앱이 배터리 최적화 때문에 알림이 늦을 수 있다고 안내하면 Android 설정에서 Sidekick Remote의 배터리 사용을 ‘제한 없음’으로 바꾸세요. 절전 상태에서는 알림이 늦어질 수 있으며, 클라우드 푸시는 아닙니다. 처음 켤 때 과거 완료 알림을 한꺼번에 보내지 않습니다. 연결 중 끊겼다가 복구되면 PC에 남은 최근 알림 최대 128개를 확인합니다.

**Chrome 원격 디버깅은 휴대폰 연결에 필요 없습니다.** Sidekick의 Codex가 현재 Chrome 탭을 읽거나 조작할 때만 사용하는 별도 기능입니다.

## 연결이 안 될 때

PC와 Sidekick이 켜져 있는지, 선택한 주소가 현재 네트워크 주소인지 확인하세요. Wi-Fi의 기기 간 통신 차단이나 Windows 방화벽이 TCP 47321 연결을 막을 수 있습니다. 앱은 공유기의 포트 포워딩이나 방화벽 설정을 자동으로 바꾸지 않습니다. 인터넷에 포트를 공개할 필요는 없습니다.

휴대폰에 ‘PC의 Sidekick이 오래됐어요’ 띠가 보이면 PC의 Sidekick을 업데이트하세요. 그 전까지는 휴대폰에서 모델·생각 수준·권한 모드를 고르는 칩이 보이지 않습니다.

PC 네트워크 주소가 바뀌면 PC에서 새 연결 QR을 만들어 휴대폰으로 다시 스캔합니다(이미 연결된 휴대폰은 주소만 확인하고 다시 승인받지 않습니다). 인증서가 바뀌면 연결을 해제하고 새 연결 QR로 다시 연결합니다. PC 또는 휴대폰 시간이 크게 어긋나도 서명 요청이 거절됩니다.

정상 종료 뒤 PC가 켜질 때 선택한 네트워크가 아직 준비되지 않았다면 30초마다 같은 주소가 돌아왔는지 확인해 다시 엽니다(열기에 계속 실패하면 1분에서 30분까지 간격이 늘어납니다). 다른 주소를 자동으로 고르지는 않습니다. 저장 오류나 비정상 종료에 따른 보호 상태는 PC 설정에서 확인해야 합니다.

## 현재 범위

이 앱은 대화 원격 클라이언트입니다. PC 화면 스트리밍, 원격 데스크톱 조작, 모바일 파일 첨부, 클라우드 푸시는 포함하지 않습니다. 세션 전체 권한 허용, 비밀 입력·URL 인증·필드가 있는 입력 양식은 PC에서 처리합니다(권한 모드는 ‘도구·질문 승인’ 권한이 있는 휴대폰에서 바꿀 수 있습니다). Google AI는 PC에서 지원하는 동작만 수행합니다.

HTTPS 인증서 고정과 휴대폰별 서명을 사용하며, 승인되지 않은 휴대폰은 대화를 읽을 수 없습니다. 휴대폰 키는 Android Keystore에, PC 키와 연결된 휴대폰 목록은 Windows 사용자 계정에 보호해 저장합니다. Android 백업에는 대화·초안·기기 정보가 포함되지 않습니다.

재전송 방지와 전송 ID 중복 처리는 서버 프로세스가 유지되는 동안 적용됩니다. PC 재시작을 넘는 전송의 정확히 한 번 처리를 보장하지 않습니다. 결과가 불확실한 전송은 먼저 대화 기록을 확인하세요.

Android 앱의 검증 기록은 [android/VALIDATION.md](../android/VALIDATION.md)에 실제 기기·외부 네트워크에서 확인한 범위와 구분해서 적습니다. 프로토콜의 세부 제한은 [REMOTE_PROTOCOL.md](REMOTE_PROTOCOL.md)를 참고하세요.

## 개발용 Android 빌드

```powershell
./scripts/build-android.ps1
```

Java 17, Android SDK와 Gradle이 필요합니다. 스크립트는 `D:\android-build\sidekick-remote\`에 `SidekickRemote-<버전>-debug.apk`(디버그 서명, 에뮬레이터 시험용)를 만들고, `~/.sidekick-release/android-release.properties`(저장소 밖, `storeFile`·`storePassword`·`keyAlias`·`keyPassword`)가 있으면 `SidekickRemote-<버전>.apk`(배포용 서명, 디버그 불가)도 만듭니다. 배포용 APK는 SHA-256과 서명 인증서(`apksigner verify --print-certs`)를 함께 출력합니다. 실제 휴대폰에는 배포용 APK만 설치하세요. Play Store 출시는 별도입니다.
